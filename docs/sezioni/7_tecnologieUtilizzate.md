Data la richiesta del cliente di sviluppare un'applicazione versatile ed utilizzabile su qualsiasi dispositivo, abbiamo optato per la realizzazione di una **Web-App** utilizzando le seguenti tecnologie:

1.  **Next.js** - un framework di sviluppo web open-source basato su React, utilizzato per la creazione di applicazioni web moderne e performanti.
2.  **Supabase** - piattaforma che fornisce un completo stack di sviluppo per la creazione di applicazioni web e mobili con database PostgreSQL.
3.  **Prisma** - un moderno strumento di accesso ai dati e ORM (Object-Relational Mapping) che semplifica l'interazione con i database nelle applicazioni.
4.  **Mantine** - libreria di componenti React che garantisce un'ottima esperienza utente e una facile implementazione agli sviluppatori.
5.  **Typescript** - linguaggio che consente agli sviluppatori di specificare il tipo di variabili, parametri di funzioni e valori di ritorno delle funzioni.
6.  **ESLint** - strumento che permette di analizzare il codice sorgente JavaScript e individuare potenziali errori.
